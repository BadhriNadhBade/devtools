{% comment %}
  Worth stating plainly even now that the tool can verify. Without a key it
  reads the token and nothing more, and people do conflate the two.
{% endcomment %}


  With no key in the box this decodes the token and does not check it — anyone can mint a token with any payload. With a key it verifies the signature here, in this tab, against the algorithm the header names; a token that verifies against a key you fetched yourself is trustworthy, one that verifies against a key the token pointed you at is not.
