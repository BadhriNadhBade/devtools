  Cheatsheet
  

    
.
any character except newline

    
\w \d \s
word, digit, whitespace

    
\W \D \S
not word, digit, whitespace

    
[abc]
any of a, b or c

    
[^abc]
not a, b or c

    
[a-g]
character between a and g

    
^abc$
start / end of the string

    
\b \B
word, not-word boundary

    
\t \n \r
tab, linefeed, carriage return

    
(abc)
capture group

    
(?<name>abc)
named capture group

    
\1
backreference to group 1

    
(?:abc)
non-capturing group

    
(?=abc) (?!abc)
positive / negative lookahead

    
(?<=abc) (?<!abc)
positive / negative lookbehind

    
a* a+ a?
0 or more, 1 or more, 0 or 1

    
a{5} a{2,}
exactly five, two or more

    
a{1,3}
between one and three

    
a+? a{2,}?
match as few as possible

    
ab|cd
match ab or cd

  

  

    
$&
in a replacement: the whole match

    
$1 $<name>
in a replacement: a capture group

    
$$
in a replacement: a literal dollar sign
