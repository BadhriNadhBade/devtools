Worth a look

JSON is reformatted by changing whitespace and nothing else, so a number too long for a double and keys that a parser would reorder both come out exactly as they went in. YAML has to be rebuilt from its structure, which loses comments and blank lines — you will be told when there are any to lose. The tree and the path box both read the document through a parser, so a number too large for a double is rounded there even though the formatted output beside it is not.
