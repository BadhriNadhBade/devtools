Drop a file here to checksum it.

{% comment %} The reason most people are here: they have a digest from somewhere else and want to know whether this file is that file. Takes a bare digest or a whole line of `sha256sum` output, because that is what gets copied. {% endcomment %}

Digests

CRC32 detects accidental corruption and nothing else. MD5 and SHA-1 are broken for anything security-related — treat all three as checksums for matching against existing values, not as a way to protect data. For storing passwords use a purpose-built function like bcrypt or Argon2, never a raw digest.
