Output
{% comment %} The other direction. An identifier out of a log line carries its version, its variant and — for half the versions in use — the time it was made, none of which is legible by eye. {% endcomment %}
Inspect

v4 and v7 are drawn from crypto.getRandomValues. v5 is a SHA-1 of the namespace and name, so it is reproducible rather than random — the same two inputs give the same UUID on any machine. v1 is deliberately not offered: it embeds the generating machine's MAC address, and v7 sorts by time without that.
