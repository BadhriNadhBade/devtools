YAML {% comment %} Empty in the markup and filled by the script, which also unhides it — with JavaScript off there is nowhere for a result to go. {% endcomment %}
{% comment %} Worth being upfront about, in both directions. The YAML reader is a subset, and the flat formats cannot hold what the nested ones can — so rather than inventing an encoding nobody else reads back, each one says what it did. {% endcomment %}

Plain YAML scalars are resolved against the 1.2 core schema, so yes, off and 2024-01-01 stay strings while true, 0x1f and 1e3 do not. Anchors, aliases, merge keys and block scalars are all read; a stream holding more than one document is not, because JSON has nowhere to put the second one.

CSV is a table and will not hold a nested document — it says so rather than guessing. .env and query strings are flat, so a nested document is flattened into dotted or underscored keys on the way out, and comes back as those keys rather than as the structure it started with.
